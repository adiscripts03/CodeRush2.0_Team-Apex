Create a high-fidelity, sophisticated UI dashboard design for an AI-Assisted Disaster Management Command Center called "Project Sentinel: Wanadongri Flood Response." The aesthetic should be modern, "Glassmorphic," functional, and authoritative, suitable for use in an Emergency Operations Center (EOC). The design needs a balanced layout that emphasizes a massive central interactive map while flanking it with actionable data panels.

Layout Structure:

Grid: Standard 12-column grid application dashboard.

Navigation: A slim, dark, vertical icon-only navigation bar on the extreme left.

Header: A clean header spanning the top of the application.

Main Content Area (The Map): A vast, central geospatial visualization map area taking up 60% of the screen width.

Left Sidebar (Layers & Filters): A 20% width collapsible panel.

Right Sidebar (Decision Intelligence & AI Agent): A 20% width critical action panel.

Bottom Section (Timeline/Simulation Controls): A horizontal strip at the base of the map.

1. Color Palette & Typography
Base Theme: Dark Mode (Ops Center aesthetic). Background: Deep Navy (#0F172A). UI Panels: Slightly translucent Deep Gray (#1F2937) with a subtle blur effect (Glassmorphism).

Action Colors: Primary UI Accent: Bright Cyan (#06B6D4). Human Approval Button: Safe Green (#10B981). Emergency Warnings: Hazard Orange (#F97316). Immediate Danger/Flood Zone: Danger Red (#EF4444).

Typography: Clear, functional sans-serif typeface (e.g., Inter or SF Pro). Large, bold, technical headings; precise, monospaced tabular data.

2. Detailed Component Breakdown
A. Header (Top Nav):

Left: "PROJECT SENTINEL" (Logo + Bold Cyan Text) / "Wanadongri Ops Center" (Subtitle).

Center: A large, bold clock display showing "UTC 14:32:01" (Monospaced) / "Local (IST): 20:02:01."

Right: System Status Indicator: Pulse animation "SYSTEM ONLINE (GREEN)" / "Satellite: DEGRADED (ORANGE) / AI: OPTIMAL." User profile avatar.

B. Left Sidebar (Layers & Geospatial Controls):

A panel with a list of expandable/collapsible layer categories:

[ICON: SATELLITE] Baseline Map: Satellite/Hybrid (Selected), Terrain, Dark Gray.

[ICON: ALERT-TRIANGLE] Hazard Layers: Flood Extent (Red Polygon, 60% opacity), Estimated Depth (Color Gradient legend).

[ICON: DATABASE] Infrastructure: Hospitals (H icon, Blue), Shelters (Tent icon, Green), Schools (Book icon, Yellow), River Gauges (Wave icon, Cyan). (Checkboxes to toggle visibility).

[ICON: CLOUD-RAIN] Environmental Feeds: Weather Radar (Animated overlay option), Soil Moisture Heatmap.

The map background is a detailed satellite view of the Wanadongri area (residential streets, the river, key buildings visible).
